Video to Audio now lists video input formats explicitly, matching the other tools.

- Displays MP4, MOV, MKV, WebM, AVI, M4V, WMV, ASF, FLV, F4V, MPEG, MPG, TS, MTS, M2TS, VOB, OGV, 3GP, 3G2, and MXF.
- Lists these formats in tool search as well.
- Includes the format-list update in the desktop executable and installer.

Windows 10/11, 64-bit: run **Convertor_0.2.2_x64-setup.exe**, or extract the entire portable ZIP and launch Convertor.exe. Processing engines are included. Builds are unsigned.
