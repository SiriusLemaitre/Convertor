YouTube downloads now use the video title as the output filename.

- Applies to audio, video, and GIF exports.
- Preserves Unicode titles and replaces characters Windows does not allow in filenames.
- Adds numbered suffixes when a filename already exists, without overwriting files.
- Falls back to the existing filename if a usable title is unavailable.

Windows 10/11, 64-bit: run **Convertor_0.2.3_x64-setup.exe**, or extract the entire portable ZIP and launch Convertor.exe. Processing engines are included. Builds are unsigned.
