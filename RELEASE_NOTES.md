Convertor 0.4.0

- YouTube downloads default to the user's OS Downloads folder. Selected folders still take precedence.
- Native Windows x64, macOS Intel/Apple Silicon, and Linux x64 packages include conversion engines and their runtime dependencies.
- Windows setup includes the offline WebView2 installer; Linux AppImage includes its media framework.
- The standalone website converts files locally without installing the desktop app. YouTube downloading is available in the desktop app.
- Shorter README with platform downloads, requirements, and development commands.

Packages are unsigned. macOS may require first-launch approval in Privacy & Security. Linux targets Ubuntu 22.04+ compatible desktops; AppImages support --appimage-extract-and-run when FUSE is unavailable.
