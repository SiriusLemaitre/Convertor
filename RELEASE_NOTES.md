Convertor is now available in your browser alongside the Windows desktop app.

- Public web page: https://siriuslemaitre.github.io/Convertor/
- Choose **Open hosted page** in the desktop toolbar to pair the web page with your computer.
- Choose **Open in browser** for a fully offline local page.
- Portable ZIPs include **Start-Web.cmd** and **Start-Web-Hosted.cmd**. Installed users can launch Convertor.exe with --web or --web-hosted.
- Conversion, previews, progress, cancellation, and settings use the same native engines. Files stay on your computer; GitHub Pages hosts only the interface.
- The local helper uses a random loopback port and a private session token. Allow local network access if your browser asks. Use Add files in the browser; desktop drag-and-drop remains available.
- The public page can be browsed anywhere. Processing requires the Windows helper running on the same computer. Closing the browser leaves the helper running; Quit Convertor stops it.

Windows 10/11, 64-bit: run **Convertor_0.3.0_x64-setup.exe**, or extract the entire portable ZIP. Processing engines are included. Builds are unsigned.
