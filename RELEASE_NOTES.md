Convertor 0.5.0

- Export PDF text to Markdown with page sections. This works with selectable text; OCR is not included.
- Crop videos using aspect-ratio presets or a custom pixel rectangle, then export to MP4.
- Adjust video and image crops visually with draggable crop editors and previews.
- Updated tool list in the README.
- Retry Windows engine downloads after transient failures during release builds.

Windows x64, macOS Intel/Apple Silicon, and Linux x64 packages include conversion engines and runtime dependencies. File conversion also runs locally in the standalone website; YouTube downloading requires the desktop app.

Packages are unsigned. macOS may require first-launch approval in Privacy & Security. Linux targets Ubuntu 22.04+ compatible desktops; AppImages support --appimage-extract-and-run when FUSE is unavailable.
